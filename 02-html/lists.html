HTML Lists

📑 Λίστες HTML

Οργάνωση πληροφοριών σε λίστες

📑 Τύποι Λιστών

📌 Unordered List (ul)

Λίστα με κουκκίδες - χωρίς σειρά

<ul>
    <li>Στοιχείο 1</li>
    <li>Στοιχείο 2</li>
    <li>Στοιχείο 3</li>
</ul>
  • Στοιχείο 1
  • Στοιχείο 2
  • Στοιχείο 3

🔢 Ordered List (ol)

Αριθμημένη λίστα - με σειρά

<ol>
    <li>Πρώτο</li>
    <li>Δεύτερο</li>
    <li>Τρίτο</li>
</ol>
  1. Πρώτο
  2. Δεύτερο
  3. Τρίτο

📖 Description List (dl)

Λίστα ορισμών/περιγραφών

<dl>
    <dt>HTML</dt>
    <dd>Γλώσσα σήμανσης</dd>
    <dt>CSS</dt>
    <dd>Styling</dd>
</dl>
HTML
Γλώσσα σήμανσης
CSS
Styling

⚙️ Attributes για Ordered Lists

type - Τύπος αρίθμησης

type="1"
  1. Ένα
  2. Δύο
type="a"
  1. Ένα
  2. Δύο
type="A"
  1. Ένα
  2. Δύο
type="i"
  1. Ένα
  2. Δύο
type="I"
  1. Ένα
  2. Δύο

start - Αρχική τιμή

<ol start="5">
  1. Πέντε
  2. Έξι
  3. Εφτά

reversed - Αντίστροφη σειρά

<ol reversed>
  1. Τρία
  2. Δύο
  3. Ένα

🔄 Nested Lists (Ένθετες)

<ul>
    <li>Φρούτα

            <li>Μήλο</li>

            <li>Αγγούρι</li>
        </ul>
    </li>
</ul>
