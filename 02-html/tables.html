📊 Πίνακες HTML

Οργάνωση δεδομένων σε γραμμές και στήλες

📊 Δομή Πίνακα

💡

Οι πίνακες χρησιμοποιούνται για να εμφανίσουμε δεδομένα σε οργανωμένη μορφή γραμμών και στηλών.

Βασική Δομή Πίνακα
<table>
    <thead>
        <tr>
            <th>Κεφαλίδα 1</th>
            <th>Κεφαλίδα 2</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Δεδομένα 1</td>
            <td>Δεδομένα 2</td>
        </tr>
    </tbody>
</table>
Κεφαλίδα 1Κεφαλίδα 2

🏷️ Table Tags

<table>

Ορίζει τον πίνακα

<thead>

Κεφαλίδα πίνακα

<tbody>

Σώμα πίνακα

<tfoot>

Υποσέλιδο πίνακα

<tr>

Table Row (γραμμή)

<th>

Table Header (κεφαλίδα κελιού)

<td>

Table Data (κελί δεδομένων)

🔗 Colspan & Rowspan

Μπορούμε να συγχωνεύσουμε κελιά:

colspan (οριζόντια)

<td colspan="2">
Colspan 2
AB

rowspan (κάθετα)

<td rowspan="2">
RowspanA
B
