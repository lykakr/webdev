🎥 Video Element

Βασική Σύνταξη Video 
<video src="video.mp4" controls width="640" height="360">
    Ο browser σας δεν υποστηρίζει video.
</video>

🎬 Demo video με controls

⚙️ Video Attributes

Attribute Περιγραφή Παράδειγμα
src URL του video αρχείου src="video.mp4"
controls Εμφανίζει play, pause, volume κλπ controls
autoplay Αυτόματη αναπαραγωγή (⚠️ muted required) autoplay muted
loop Επανάληψη στο τέλος loop
muted Σίγαση ήχου muted
poster Εικόνα πριν το play poster="thumbnail.jpg"
preload Πώς να φορτωθεί (none/metadata/auto) preload="metadata"
width/height Διαστάσεις σε pixels width="640" height="360"
playsinline Inline play σε mobile (όχι fullscreen) playsinline

📁 Πολλαπλές Πηγές (Fallback)

⚠️

Διαφορετικοί browsers υποστηρίζουν διαφορετικά formats. Χρησιμοποίησε πολλαπλά <source> για μέγιστη συμβατότητα!

Multiple Sources
<video controls width="640" poster="thumbnail.jpg">
    <source src="video.webm" type="video/webm">
    <source src="video.mp4" type="video/mp4">
    <source src="video.ogg" type="video/ogg">
    <!-- Fallback για παλιούς browsers -->
    <p>Ο browser σας δεν υποστηρίζει HTML5 video.
       <a href="video.mp4">Κατεβάστε το video</a>.
    </p>
</video>

📊 Video Formats:

MP4 (H.264) ✅ Όλοι οι browsers
WebM ✅ Chrome, Firefox, Edge
Ogg ⚠️ Firefox, Chrome

📺 iframe Element

💡

Το <iframe> (inline frame) ενσωματώνει μια άλλη HTML σελίδα μέσα στην τρέχουσα. Χρησιμοποιείται για YouTube videos, Google Maps, social widgets κ.λπ.

Βασική Σύνταξη iframe 
<iframe 
    src="https://example.com" 
    width="600" 
    height="400"
    title="Περιγραφή περιεχομένου"
></iframe>

📹 YouTube Embed

YouTube Embed Code
<iframe 
    width="560" 
    height="315" 
    src="https://www.youtube.com/embed/VIDEO_ID" 
    title="YouTube video player" 
    frameborder="0" 
    allow="accelerometer; autoplay; clipboard-write; 
           encrypted-media; gyroscope; picture-in-picture" 
    allowfullscreen
></iframe>

💡 Πώς να πάρεις YouTube Embed Code:

  1. Άνοιξε το video στο YouTube
  2. Κάνε κλικ στο Share (Κοινοποίηση)
  3. Επίλεξε Embed (Ενσωμάτωση)
  4. Αντίγραψε τον κώδικα!

⚙️ iframe Attributes

Attribute Περιγραφή
src URL της σελίδας που θα ενσωματωθεί
width / height Διαστάσεις του iframe
title Περιγραφή για accessibility (⚠️ Απαραίτητο!)
frameborder 0 = χωρίς border (deprecated, χρησιμοποιείστε CSS)
allowfullscreen Επιτρέπει fullscreen mode
loading lazy = φόρτωση όταν χρειαστεί (performance)
sandbox Περιορισμοί ασφαλείας
allow Permissions policy (camera, microphone κλπ)
🔒

Ασφάλεια: Ορισμένες σελίδες (π.χ. Google, Facebook) δεν επιτρέπουν να ενσωματωθούν σε iframe για λόγους ασφαλείας (X-Frame-Options header).

🔌 Embed & Object Elements

<embed>

Ενσωμάτωση εξωτερικού περιεχομένου (PDF, Flash, κλπ)

<embed 
    src="document.pdf" 
    type="application/pdf"
    width="600" 
    height="400"
>
  • Self-closing tag
  • Χρησιμοποιείται για PDFs
  • Δεν έχει fallback content

<object>

Παρόμοιο με embed, αλλά με fallback

<object 
    data="document.pdf" 
    type="application/pdf"
    width="600" 
    height="400"
>
    <p>Fallback: 
       <a href="document.pdf">
          Download PDF
       </a>
    </p>
</object>
  • Υποστηρίζει fallback content
  • Πιο flexible
  • Καλύτερο για PDFs

📄 PDF Embed Παράδειγμα

Ενσωμάτωση PDF
<!-- Μέθοδος 1: embed -->
<embed src="document.pdf" type="application/pdf" width="100%" height="500">

<!-- Μέθοδος 2: object με fallback -->
<object data="document.pdf" type="application/pdf" width="100%" height="500">
    <p>Δεν μπορεί να εμφανιστεί το PDF. 
       <a href="document.pdf">Κατεβάστε το εδώ</a>.
    </p>
</object>

<!-- Μέθοδος 3: iframe (πιο συμβατό) -->
<iframe src="document.pdf" width="100%" height="500" title="PDF Document">
    <p><a href="document.pdf">Download PDF</a></p>
</iframe>

📱 Responsive Media

Για να κάνεις τα video/iframe responsive (να προσαρμόζονται στην οθόνη):

Responsive Video Container (CSS)
<!-- HTML -->
<div class="video-container">
    <iframe src="https://www.youtube.com/embed/VIDEO_ID"></iframe>
</div>

<!-- CSS -->
<style>
.video-container {
    position: relative;
    padding-bottom: 56.25%; /* 16:9 aspect ratio */
    height: 0;
    overflow: hidden;
}

.video-container iframe {
    position: absolute;
    top: 0;
    left: 0;
    width: 100%;
    height: 100%;
    border: 0;
}
</style>

📐 Common Aspect Ratios:

16:9 padding-bottom: 56.25%
4:3 padding-bottom: 75%
1:1 padding-bottom: 100%
21:9 padding-bottom: 42.85%

📝 Υπότιτλοι με <track>

Πρόσθεσε υπότιτλους, captions ή descriptions στα video:

Video με Υπότιτλους
<video controls width="640">
    <source src="movie.mp4" type="video/mp4">
    
    <!-- Υπότιτλοι -->
    <track 
        kind="subtitles" 
        src="subtitles_el.vtt" 
        srclang="el" 
        label="Ελληνικά"
        default
    >
    <track 
        kind="subtitles" 
        src="subtitles_en.vtt" 
        srclang="en" 
        label="English"
    >
    
    <!-- Captions για κωφούς -->
    <track 
        kind="captions" 
        src="captions.vtt" 
        srclang="el" 
        label="Ελληνικά (CC)"
    >
</video>

📋 Track Kinds:

  • subtitles - Μετάφραση διαλόγων
  • captions - Διάλογοι + ήχοι (για κωφούς)
  • descriptions - Περιγραφή για τυφλούς
  • chapters - Κεφάλαια video
  • metadata - Data για scripts
