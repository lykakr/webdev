🖼️ Το <img> Tag

💡

Το <img> tag χρησιμοποιείται για να εμφανίσουμε εικόνες. Είναι self-closing tag - δεν χρειάζεται closing tag!

Βασική Σύνταξη 
<img src="photo.jpg" alt="Περιγραφή εικόνας">

🔬 Ανάλυση:

<img src="image.jpg" alt="Description" >
src = source (πηγή/διαδρομή εικόνας)
alt = alternative text (εναλλακτικό κείμενο)
⚠️

ΣΗΜΑΝΤΙΚΟ: Το alt attribute είναι υποχρεωτικό! Χρησιμεύει για:

  • 🔍 SEO (μηχανές αναζήτησης)
  • ♿ Προσβασιμότητα (screen readers)
  • 🖼️ Εμφανίζεται αν η εικόνα δεν φορτώσει

⚙️ Attributes Εικόνας

src

src="path/image.jpg"

Η διαδρομή της εικόνας (υποχρεωτικό)

alt

alt="Περιγραφή"

Εναλλακτικό κείμενο (υποχρεωτικό)

width

width="300"

Πλάτος σε pixels

height

height="200"

Ύψος σε pixels

title

title="Tooltip"

Tooltip κείμενο (hover)

loading

loading="lazy"

Lazy loading για performance

Πλήρες Παράδειγμα
<img 
    src="images/photo.jpg" 
    alt="Μια όμορφη φωτογραφία τοπίου" 
    width="600" 
    height="400"
    title="Κάνε κλικ για μεγέθυνση"
    loading="lazy"
>

📁 Μορφές Εικόνας

📷

.JPG / .JPEG

  • ✅ Φωτογραφίες
  • ✅ Μικρό μέγεθος
  • ❌ Χωρίς διαφάνεια
  • ❌ Απώλεια ποιότητας
🎨

.PNG

  • ✅ Διαφάνεια (transparency)
  • ✅ Χωρίς απώλεια ποιότητας
  • ✅ Γραφικά, logos
  • ❌ Μεγαλύτερο μέγεθος
🎬

.GIF

  • ✅ Animations
  • ✅ Διαφάνεια
  • ❌ Μόνο 256 χρώματα
  • ❌ Χαμηλή ποιότητα
🔷

.SVG

  • ✅ Vector (scalable)
  • ✅ Τέλειο για icons/logos
  • ✅ Πολύ μικρό μέγεθος
  • ❌ Όχι για φωτογραφίες
🌐

.WebP

  • ✅ Μοντέρνα μορφή
  • ✅ Μικρότερο μέγεθος
  • ✅ Διαφάνεια + Animation
  • ⚠️ Έλεγξε compatibility

🏷️ Figure & Figcaption

Για εικόνες με λεζάντα, χρησιμοποιούμε τα semantic tags:

Figure με Λεζάντα
<figure>
    <img src="sunset.jpg" alt="Ηλιοβασίλεμα στη Σαντορίνη">
    <figcaption>Ηλιοβασίλεμα στην Οία, Σαντορίνη - 2024</figcaption>
</figure>

📱 Responsive Εικόνες

1. CSS max-width

Η πιο απλή μέθοδος:

img { max-width: 100%; height: auto; }

2. srcset Attribute

Διαφορετικές εικόνες για διαφορετικά μεγέθη οθόνης:

<img 
    src="small.jpg"
    srcset="small.jpg 480w,
            medium.jpg 800w,
            large.jpg 1200w"
    sizes="(max-width: 600px) 480px,
           (max-width: 900px) 800px,
           1200px"
    alt="Responsive image"
>

3. Picture Element

Πλήρης έλεγχος για διαφορετικές συσκευές:

<picture>
    <source media="(max-width: 600px)" srcset="mobile.jpg">
    <source media="(max-width: 1200px)" srcset="tablet.jpg">
    <img src="desktop.jpg" alt="Responsive">
</picture>
