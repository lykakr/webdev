📋 Φόρμες HTML

Συλλογή δεδομένων από τους χρήστες

📋 Τι είναι οι Φόρμες;

💡

Οι φόρμες (forms) επιτρέπουν στους χρήστες να εισάγουν δεδομένα: κείμενο, επιλογές, αρχεία κ.λπ. Χρησιμοποιούνται για login, εγγραφή, αναζήτηση, επικοινωνία.

Βασική Φόρμα
<form action="/submit" method="POST">
    <label for="name">Όνομα:</label>
    <input type="text" id="name" name="name" required>
    
    <label for="email">Email:</label>
    <input type="email" id="email" name="email">
    
    <button type="submit">Υποβολή</button>
</form>

⚙️ Σημαντικά Attributes

Attribute Χρήση Παράδειγμα
required Υποχρεωτικό πεδίο <input required>
placeholder Κείμενο υπόδειξης <input placeholder="Γράψε...">
value Προκαθορισμένη τιμή <input value="default">
disabled Απενεργοποιημένο <input disabled>
readonly Μόνο ανάγνωση <input readonly>
min/max Ελάχιστη/Μέγιστη τιμή <input type="number" min="0" max="100">
pattern Regular Expression <input pattern="[A-Za-z]+">
