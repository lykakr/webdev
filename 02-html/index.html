🌐 1. Τι είναι η HTML;

💡

HTML (HyperText Markup Language) είναι η τυπική γλώσσα σήμανσης για τη δημιουργία ιστοσελίδων. Περιγράφει τη δομή μιας ιστοσελίδας χρησιμοποιώντας ετικέτες (tags).

🔑 Βασικά σημεία:

  • HTML = HyperText Markup Language
  • Δεν είναι γλώσσα προγραμματισμού, είναι γλώσσα σήμανσης
  • Χρησιμοποιεί ετικέτες (tags) για να ορίσει στοιχεία
  • Οι browsers "διαβάζουν" την HTML και την εμφανίζουν
  • Η τρέχουσα έκδοση είναι HTML5

📅 Σύντομη Ιστορία:

1991

Ο Tim Berners-Lee δημιουργεί την HTML

1995

HTML 2.0 - Πρώτο επίσημο standard

1999

HTML 4.01 - Ευρέως χρησιμοποιούμενη

2014

HTML5 - Σύγχρονη έκδοση με multimedia

🏗️ 2. Βασική Δομή HTML

📄 index.html 
<!DOCTYPE html>
<html lang="el">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Η Πρώτη μου Σελίδα</title>
</head>
<body>
    <h1>Καλώς ήρθες!</h1>
    <p>Αυτή είναι η πρώτη μου ιστοσελίδα.</p>
</body>
</html>
<!DOCTYPE html>

Δηλώνει ότι είναι HTML5 έγγραφο

<html>

Το ριζικό στοιχείο - περιέχει τα πάντα

<head>

Μεταδεδομένα - δεν εμφανίζονται στη σελίδα

<body>

Το περιεχόμενο που βλέπει ο χρήστης

🏷️ 3. Tags και Elements

Ετικέτα (Tag)

Η ετικέτα ανοίγματος ή κλεισίματος

Ολόκληρο το στοιχείο με περιεχόμενο

⚙️ 5. Ιδιότητες (Attributes)

⚠️

Οι ιδιότητες παρέχουν επιπλέον πληροφορίες για τα HTML elements. Γράφονται πάντα στο opening tag.

id

<div id="header">

Μοναδικό αναγνωριστικό

class

<p class="intro">

Κατηγορία/ομάδα για styling

href

<a href="url">

Διεύθυνση συνδέσμου

src

<img src="photo.jpg">

Πηγή αρχείου

alt

<img alt="Περιγραφή">

Εναλλακτικό κείμενο

style

<p style="color:red">

Inline CSS styling

title

<abbr title="...">

Tooltip κείμενο

target

<a target="_blank">

Πού ανοίγει ο σύνδεσμος
