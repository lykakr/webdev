🏛️ Semantic HTML5

Δώσε νόημα και δομή στις σελίδες σου με semantic elements

⏱️ ~35 λεπτά 📊 Μεσαίο

🤔 Τι είναι το Semantic HTML;

💡

Semantic HTML σημαίνει χρήση HTML elements που περιγράφουν το νόημα του περιεχομένου τους, όχι απλά την εμφάνισή τους. Αντί για γενικά <div>, χρησιμοποιούμε elements που "λένε" τι περιέχουν.

❌ Μη-Semantic (Παλιός τρόπος)

<div id="header">...</div>
<div id="nav">...</div>
<div id="main">
    <div class="article">...</div>
</div>
<div id="footer">...</div>

Τα div δεν λένε τίποτα για το περιεχόμενο

✅ Semantic (HTML5 τρόπος)

<header>...</header>
<nav>...</nav>
<main>
    <article>...</article>
</main>
<footer>...</footer>

Κάθε element περιγράφει το ρόλο του!

🎯 Γιατί είναι Σημαντικό;

♿

Προσβασιμότητα

Τα screen readers κατανοούν τη δομή και βοηθούν άτομα με αναπηρίες

🔍

SEO

Οι μηχανές αναζήτησης "καταλαβαίνουν" καλύτερα το περιεχόμενο

👨‍💻

Αναγνωσιμότητα

Ο κώδικας είναι πιο εύκολος στην κατανόηση και συντήρηση

🎨

Styling

📐 Δομή Σελίδας με Semantic HTML

<header> Logo, τίτλος, navigation
<nav> Κύριο μενού πλοήγησης
<main>
<article> Αυτόνομο περιεχόμενο
<section> Θεματική ενότητα
<aside> Sidebar, σχετικό περιεχόμενο
<footer> Copyright, επικοινωνία, links

📚 Τα Semantic Elements

<header> Structural

Κεφαλίδα - Εισαγωγικό περιεχόμενο ή navigation links

  • Συνήθως περιέχει logo, τίτλο, nav
  • Μπορεί να υπάρχει σε <body>, <article>, <section>
  • Ένα <header> για ολόκληρη τη σελίδα + headers μέσα σε articles
<header>
    <img src="logo.png" alt="Logo">
    <h1>Όνομα Ιστοσελίδας</h1>
    <nav>...</nav>
</header>
<nav> Navigation

Πλοήγηση - Περιέχει συνδέσμους πλοήγησης

  • Για κύρια navigation links (menu)
  • Δεν χρειάζεται για κάθε ομάδα links
  • Μπορεί να υπάρχει πάνω από ένα (main nav, footer nav)
<nav>
    <ul>
        <li><a href="/">Αρχική</a></li>
        <li><a href="/about">Σχετικά</a></li>
        <li><a href="/contact">Επικοινωνία</a></li>
    </ul>
</nav>
<main> Content

Κύριο Περιεχόμενο - Το βασικό περιεχόμενο της σελίδας

  • ⚠️ Μόνο ένα <main> ανά σελίδα!
  • Δεν περιλαμβάνει header, footer, nav, sidebars
  • Μοναδικό περιεχόμενο για κάθε σελίδα
<main>
    <h1>Τίτλος Σελίδας</h1>
    <article>...</article>
    <section>...</section>
</main>
<article> Content

Άρθρο - Αυτόνομο, επαναχρησιμοποιήσιμο περιεχόμενο

  • Blog posts, news articles, comments
  • Μπορεί να σταθεί μόνο του (share, RSS)
  • Μπορεί να περιέχει header, footer, sections
<article>
    <header>
        <h2>Τίτλος Άρθρου</h2>
        <time datetime="2024-01-15">15 Ιαν 2024</time>
    </header>
    <p>Περιεχόμενο άρθρου...</p>
    <footer>Συγγραφέας: ...</footer>
</article>
<section> Content

Ενότητα - Θεματική ομαδοποίηση περιεχομένου

  • Πρέπει να έχει επικεφαλίδα (h2, h3...)
  • Χρησιμοποιείται για να χωρίσει περιεχόμενο
  • Δεν είναι generic container (χρησιμοποίησε div γι' αυτό)
<section>
    <h2>Οι Υπηρεσίες μας</h2>
    <p>Προσφέρουμε...</p>
</section>

<section>
    <h2>Τιμοκατάλογος</h2>
    <p>Οι τιμές μας...</p>
</section>
<aside> Complementary

Πλευρικό/Συμπληρωματικό - Σχετικό αλλά ξεχωριστό περιεχόμενο

  • Sidebars, διαφημίσεις, related links
  • Pull quotes, σχετικά άρθρα
  • Περιεχόμενο που θα μπορούσε να αφαιρεθεί χωρίς να χαθεί νόημα
<aside>
    <h3>Σχετικά Άρθρα</h3>
    <ul>
        <li><a href="#">Άρθρο 1</a></li>
        <li><a href="#">Άρθρο 2</a></li>
    </ul>
</aside>
<footer> Structural

Υποσέλιδο - Πληροφορίες για το parent element

  • Copyright, στοιχεία επικοινωνίας, sitemap
  • Μπορεί να υπάρχει σε body, article, section
  • Συχνά περιέχει <address> και links
<footer>
    <p>&copy; 2024 Εταιρεία. Όλα τα δικαιώματα κατοχυρωμένα.</p>
    <nav>
        <a href="/privacy">Πολιτική Απορρήτου</a>
        <a href="/terms">Όροι Χρήσης</a>
    </nav>
    <address>Email: info@example.com</address>
</footer>

🔧 Άλλα Χρήσιμα Semantic Elements

<figure> + <figcaption>

Εικόνα/διάγραμμα με λεζάντα

<time>

Ημερομηνία/ώρα (machine-readable)

<time datetime="2024-01-15">15 Ιαν</time>
<mark>

Επισημασμένο/highlighted κείμενο

Βρήκα το αποτέλεσμα που ψάχνεις.

<details> + <summary>

Expandable/collapsible content

Κάνε κλικ για περισσότερα

Κρυφό περιεχόμενο που εμφανίζεται!

<dialog>

Modal/dialog box

<dialog open>Content</dialog>
<progress>

Progress bar

<meter>

Μέτρηση σε κλίμακα

<output>

Αποτέλεσμα υπολογισμού

<output>42</output>

🤷 Section vs Article vs Div - Πότε τι;

📰 Χρησιμοποίησε <article> όταν:

  • Το περιεχόμενο μπορεί να σταθεί μόνο του
  • Θα είχε νόημα αν το κοινοποιούσες
  • Blog post, σχόλιο, προϊόν, news item
✅ Άρθρο blog, Σχόλιο, Κάρτα προϊόντος

📑 Χρησιμοποίησε <section> όταν:

  • Ομαδοποιείς θεματικά περιεχόμενο
  • Έχει επικεφαλίδα (h2, h3...)
  • Είναι μέρος ενός μεγαλύτερου περιεχομένου
✅ Chapters, Ενότητες σελίδας, Tabs

📦 Χρησιμοποίησε <div> όταν:

  • Χρειάζεσαι container για styling
  • Δεν υπάρχει semantic σημασία
  • Απλή ομαδοποίηση για CSS/JS
✅ Wrapper, Grid container, Styling group

🔀 Flowchart Απόφασης:

Μπορεί να σταθεί μόνο του;
ΝΑΙ → <article> ΟΧΙ ↓
Έχει θεματική επικεφαλίδα;
ΝΑΙ → <section> ΟΧΙ ↓
Χρειάζεται για styling/JS;
ΝΑΙ → <div> ΟΧΙ → Μάλλον δεν χρειάζεται container

                <li><a href="/contact">Επικοινωνία</a></li>
            </ul>
        </nav>
    </header>

    <main>
        <article>
            <header>
                <h2>Τίτλος Άρθρου</h2>
                <p>Δημοσιεύτηκε: <time datetime="2024-01-15">15 Ιαν 2024</time></p>
            </header>
            
            <section>
                <h3>Εισαγωγή</h3>
                <p>Περιεχόμενο εισαγωγής...</p>
            </section>
            
            <section>
                <h3>Κύριο Θέμα</h3>
                <p>Περιεχόμενο κυρίου θέματος...</p>
                <figure>
                    <img src="image.jpg" alt="Περιγραφή">
                    <figcaption>Λεζάντα εικόνας</figcaption>
                </figure>
            </section>
            
            <footer>
                <p>Συγγραφέας: Γιάννης</p>
                <p>Κατηγορία: Τεχνολογία</p>

        </article>

        <aside>
            <h3>Σχετικά Άρθρα</h3>
            <ul>
                <li><a href="#">Άρθρο 1</a></li>
                <li><a href="#">Άρθρο 2</a></li>
            </ul>
        </aside>
    </main>

    <footer>
        <p>&copy; 2024 Το Blog μου</p>
        <address>
            Email: <a href="mailto:info@blog.gr">info@blog.gr</a>
        </address>
    </footer>
</body>
</html>

✏️ Ασκήσεις

1

Ποιο element πρέπει να χρησιμοποιήσω;

Αντιστοίχισε κάθε περίπτωση με το σωστό semantic element:

Logo και μενού στην κορυφή
Κύριο μενού πλοήγησης
Blog post που μπορεί να κοινοποιηθεί
Sidebar με σχετικά links
Copyright στο κάτω μέρος
2

Σωστό ή Λάθος;

Μπορούμε να έχουμε πολλά <main> σε μια σελίδα
Το <article> πρέπει πάντα να είναι μέσα σε <main>
Μπορούμε να βάλουμε <header> μέσα σε <article>
Το <section> πρέπει να έχει επικεφαλίδα (h2, h3...)
Το <aside> χρησιμοποιείται μόνο για sidebars
3

Μετατροπή σε Semantic HTML

Μετέτρεψε τον παρακάτω "div soup" σε semantic HTML:

❌ Πριν (divs)

<div id="header">
    <div id="logo">Logo</div>
    <div id="menu">Menu</div>
</div>
<div id="content">
    <div class="post">
        <div class="post-title">Title</div>
        <div class="post-body">Content</div>
    </div>
</div>
<div id="sidebar">Links</div>
<div id="footer">Copyright</div>
