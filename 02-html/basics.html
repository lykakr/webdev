🏗️ Βασική Δομή HTML

DOCTYPE, html, head, body - Τα θεμέλια κάθε ιστοσελίδας

⏱️ ~20 λεπτά 📊 Αρχάριο

📄 Η Δομή ενός HTML Εγγράφου

💡

Κάθε HTML έγγραφο έχει μια συγκεκριμένη δομή που πρέπει να ακολουθείται. Αυτή η δομή λέει στον browser πώς να "διαβάσει" τη σελίδα.

📄 Βασική Δομή 
<!DOCTYPE html>
<html lang="el">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Τίτλος Σελίδας</title>
</head>
<body>
    <!-- Το περιεχόμενο της σελίδας -->
</body>
</html>

🔍 Ανάλυση κάθε στοιχείου

<!DOCTYPE html>

Document Type Declaration

  • Πρέπει να είναι πρώτο στο αρχείο
  • Λέει στον browser ότι είναι HTML5
  • Δεν είναι HTML tag, είναι δήλωση
  • Δεν χρειάζεται closing tag
<html lang="el">

Root Element

  • Περιέχει όλα τα άλλα elements
  • Το lang ορίζει τη γλώσσα
  • "el" = Ελληνικά, "en" = Αγγλικά
  • Βοηθά στην προσβασιμότητα
<head>

Κεφαλή Εγγράφου

  • Μεταδεδομένα (metadata)
  • Δεν εμφανίζεται στη σελίδα
  • Περιέχει: title, meta, link, style
  • Πληροφορίες για browser & μηχανές αναζήτησης
<body>

Σώμα Εγγράφου

  • Το ορατό περιεχόμενο
  • Κείμενα, εικόνες, links, κλπ
  • Ότι βλέπει ο χρήστης
  • Μόνο ένα body ανά σελίδα

🧠 Τι μπαίνει στο <head>;

<meta charset="UTF-8">

Κωδικοποίηση χαρακτήρων (για ελληνικά!)

<meta name="viewport"...>

Responsive σε κινητά

<title>...</title>

Τίτλος στην καρτέλα browser

<meta name="description"...>

Περιγραφή για Google

<link rel="stylesheet"...>

Σύνδεση με CSS αρχείο

<style>...</style>
