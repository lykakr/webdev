🔗 Σύνδεσμοι HTML

Συνδέοντας σελίδες και πόρους στο Web

⏱️ ~25 λεπτά 📊 Βασικό

🔗 Τι είναι οι Σύνδεσμοι;

💡

Οι σύνδεσμοι (links) είναι η βάση του World Wide Web! Επιτρέπουν στους χρήστες να πλοηγούνται από σελίδα σε σελίδα, να κατεβάζουν αρχεία ή να στέλνουν email.

Βασική σύνταξη 
<a href="https://www.google.com">Πήγαινε στο Google</a>

🔬 Ανάλυση του <a> tag:

<a href="URL" > Κείμενο Συνδέσμου </a>
Tag
Attribute (href = hypertext reference)
Ορατό κείμενο (clickable)

📂 Τύποι Συνδέσμων

🌐

External Links

Σύνδεσμοι σε άλλες ιστοσελίδες

<a href="https://google.com">Google</a>
Google ↗
📁

Internal Links

Σύνδεσμοι σε σελίδες του ίδιου site

<a href="about.html">Σχετικά</a>
Σχετικά με εμάς
⚓

Anchor Links

Σύνδεσμοι σε σημείο της ίδιας σελίδας

<a href="#section2">Ενότητα 2</a>
Πήγαινε στους τύπους ↓
📧

Email Links

Ανοίγει το email client

<a href="mailto:info@example.com">Email</a>
Στείλε Email 📧
📞

Phone Links

Κλήση σε κινητά

<a href="tel:+302101234567">Κάλεσε</a>
📞 210-123-4567
📥

Download Links

Κατέβασμα αρχείων

<a href="file.pdf" download>Κατέβασε</a>
📥 Κατέβασε PDF

⚙️ Σημαντικά Attributes

Attribute Τιμές Περιγραφή Παράδειγμα
href URL Ο προορισμός του συνδέσμου href="page.html"
target _blank, _self, _parent, _top Πού ανοίγει ο σύνδεσμος target="_blank"
title Κείμενο Tooltip όταν περνάει ο κέρσορας title="Περισσότερα..."
download filename (προαιρετικό) Κατέβασμα αντί για άνοιγμα download="report.pdf"
rel noopener, nofollow, κλπ Σχέση με τον προορισμό rel="noopener"
⚠️

Σημαντικό: Όταν χρησιμοποιείς target="_blank", πρόσθεσε πάντα rel="noopener noreferrer" για ασφάλεια!

<a href="..." target="_blank" rel="noopener noreferrer">

📍 Σχετικές vs Απόλυτες Διαδρομές

🌐 Απόλυτη Διαδρομή (Absolute)

Πλήρης URL με πρωτόκολλο

https://www.example.com/page.html
  • ✅ Για εξωτερικά sites
  • ✅ Λειτουργεί παντού
  • ❌ Μεγαλύτερος κώδικας

📁 Σχετική Διαδρομή (Relative)

Σε σχέση με την τρέχουσα σελίδα

page.html Ίδιος φάκελος
images/photo.jpg Υποφάκελος
../index.html Προηγούμενος φάκελος
/about.html Από τη ρίζα του site

📁 Παράδειγμα Δομής Φακέλων:

website/
├── index.html          ← Είσαι εδώ
├── about.html
├── css/
│   └── styles.css
├── images/
│   └── logo.png
└── pages/
    ├── contact.html
    └── services.html

Από το index.html:

  • about.html → about.html
  • css/styles.css → CSS αρχείο
  • pages/contact.html → Επικοινωνία

🖥️ Αποτέλεσμα

🎯 Προκλήσεις:

1️⃣ Πρόσθεσε σύνδεσμο στο YouTube
2️⃣ Φτιάξε σύνδεσμο που ανοίγει σε νέα καρτέλα
3️⃣ Δημιούργησε ακόμα μια ενότητα (#section4)
4️⃣ Πρόσθεσε title attribute με tooltip

✏️ Ασκήσεις

1

Συμπλήρωσε τα κενά

Συμπλήρωσε τα attributes για τους συνδέσμους:

<!-- Εξωτερικός σύνδεσμος σε νέα καρτέλα -->
<a ="https://google.com" ="_blank">Google</a>

<!-- Email σύνδεσμος -->
<a href=":info@test.com">Email</a>

<!-- Anchor link -->
<a href="about">Σχετικά</a>
2

Αντιστοίχισε τον τύπο συνδέσμου

href="https://..."
href="mailto:..."
href="#section"
href="tel:..."
3

Γράψε Navigation Menu

Δημιούργησε ένα navigation menu με 4 συνδέσμους: Αρχική, Υπηρεσίες, Σχετικά, Επικοινωνία
