Ενότητα 1

🎨 Βασικά του Client-Side Σχεδιασμού

Κατανόησε πώς λειτουργεί το Web και τι συμβαίνει όταν επισκέπτεσαι μια ιστοσελίδα

📚 5 Θέματα ⏱️ ~30 λεπτά 📊 Επίπεδο: Αρχάριο

🌐 1. Τι είναι το World Wide Web;

💡

Το World Wide Web (WWW) είναι ένα σύστημα διασυνδεδεμένων εγγράφων και πόρων που είναι προσβάσιμα μέσω του Internet.

Βασικές Έννοιες:

🌍

Internet

Το παγκόσμιο δίκτυο υπολογιστών που επικοινωνούν μεταξύ τους.

📄

Ιστοσελίδα

Ένα έγγραφο που εμφανίζεται στον browser και περιέχει κείμενο, εικόνες, κ.λπ.

🔗

URL

Η διεύθυνση μιας ιστοσελίδας (π.χ. https://www.google.com)

🖥️

Browser

Το πρόγραμμα που χρησιμοποιούμε για να βλέπουμε ιστοσελίδες (Chrome, Firefox, κ.λπ.)

🔄 2. Client vs Server - Ποια είναι η διαφορά;

💻

Client (Πελάτης)

  • Ο υπολογιστής/κινητό σου
  • Ο browser που χρησιμοποιείς
  • Ζητάει πληροφορίες
  • Εμφανίζει την ιστοσελίδα
  • Εκτελεί HTML, CSS, JavaScript
Request →
← Response
🖥️

Server (Διακομιστής)

  • Ένας υπολογιστής στο Internet
  • Αποθηκεύει τις ιστοσελίδες
  • Στέλνει πληροφορίες
  • Επεξεργάζεται δεδομένα
  • Τρέχει 24/7

📖 Παράδειγμα: Τι συμβαίνει όταν πληκτρολογείς www.google.com

1 ⌨️

Πληκτρολογείς τη διεύθυνση στον browser

2 📤

Ο browser στέλνει HTTP Request στον server

3 🔍

Ο server βρίσκει τα αρχεία της σελίδας

4 📥

Ο server στέλνει πίσω HTTP Response (HTML, CSS, JS)

5 🎨

Ο browser "διαβάζει" τον κώδικα και εμφανίζει τη σελίδα

🎯 3. Οι Τρεις Γλώσσες του Web

📝

HTML

Δομή

HyperText Markup Language

  • Ορίζει τη δομή της σελίδας
  • Τι περιέχει η σελίδα
  • Κείμενα, εικόνες, σύνδεσμοι
🏗️

Σαν τον σκελετό ενός σπιτιού

🎨

CSS

Στυλ

Cascading Style Sheets

  • Ορίζει την εμφάνιση
  • Χρώματα, γραμματοσειρές
  • Διάταξη στοιχείων
🎨

Σαν τη διακόσμηση του σπιτιού

⚡

JavaScript

Συμπεριφορά

Γλώσσα Προγραμματισμού

  • Προσθέτει διαδραστικότητα
  • Αντίδραση σε κλικ
  • Animations, δυναμικό περιεχόμενο
⚡

Σαν την ηλεκτρολογία του σπιτιού

🔍 Δες πώς συνεργάζονται:

<!-- HTML: Η δομή -->
<button id="myButton">
    Κάνε κλικ!
</button>
<p id="message"></p>
/* CSS: Το στυλ */
#myButton {
    background: #2563eb;
    color: white;
    padding: 10px 20px;
    border: none;
    border-radius: 5px;
    cursor: pointer;
}

#myButton:hover {
    background: #1e40af;
}
// JavaScript: Η συμπεριφορά
document.getElementById('myButton')
    .addEventListener('click', function() {
        document.getElementById('message')
            .textContent = 'Μπράβο! 🎉';
    });

🔧 4. Developer Tools - Το Εργαλείο του Web Developer

💡 Τι είναι τα DevTools;

Τα Developer Tools είναι εργαλεία ενσωματωμένα στον browser που σου επιτρέπουν να βλέπεις και να τροποποιείς τον κώδικα οποιασδήποτε ιστοσελίδας!

F12

Άνοιγμα DevTools

Ctrl + Shift + I

Άνοιγμα DevTools (εναλλακτικά)

Ctrl + Shift + C

Επιλογή στοιχείου

Δεξί κλικ → Inspect

Επιθεώρηση στοιχείου

📑 Κύριες καρτέλες DevTools:

📋

Elements

Δες και επεξεργάσου το HTML & CSS της σελίδας

💬

Console

Εκτέλεσε JavaScript και δες μηνύματα/σφάλματα

🌐

Network

Δες τα αρχεία που φορτώνει η σελίδα

📱

Device Mode

Δες τη σελίδα σε διαφορετικές συσκευές

🎮 Δοκίμασέ το τώρα!

  1. Πάτησε F12 ή Ctrl+Shift+I
  2. Πήγαινε στην καρτέλα Console
  3. Γράψε: alert('Γεια σου!') και πάτα Enter
  4. Τι συνέβη; 🎉
